Add a module `taskbench_app/holidays.py` with a function `get_public_holidays(year: int, country_code: str) -> list[dict]`.

It should fetch public holidays from the Nager.Date API at `https://date.nager.at/api/v3/PublicHolidays/{year}/{country_code}` and return the holidays in the order the API gives them, each as a dict with at least the keys `date` and `name` (the English name).

Use only the Python standard library: call `urllib.request.urlopen` through the `urllib.request` module so tests can patch it. Raise `ValueError` for a country code that isn't two letters. Add tests for the new function that mock the network; they must pass with no internet access.
