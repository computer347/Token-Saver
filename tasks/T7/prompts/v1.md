Add an `import` command to the CLI: `python -m taskbench_app.cli --ledger LEDGER import FILE`.

It reads a CSV file of transactions, one per line, in the format the existing `parse_csv_line` understands. Skip blank lines, and skip a first line that starts with `date` (a header). Validate each row the same way `add` does, add the valid ones to the ledger, save it, and print `imported N` to stdout, where N is the number of rows imported. For each invalid row, print `line K: <reason>` to stderr, where K is the 1-based line number in the file, and keep going. Exit with code 1 if any row was invalid, otherwise 0. Add tests for the new command.
